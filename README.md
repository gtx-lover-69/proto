# Proto!

Proto is a tiny handheld games console based on the Raspberry Pi Pico 2W. I chose the wireless connectivity version for bluetooth support.

It has a full colour LCD, 8 buttons in the form of 2 d-pads on each side, and semi-stereo speakers near the middle.
Proto also features a USB-C port for charging (with a dedicated RGB LED), a 3.5mm headphone jack, and a Micro SD card slot.

You can view the 3d model [here](https://3dviewer.net/#model=https://github.com/gtx-lover-69/proto/blob/main/proto.step)
